# 어둑시니 (Eoduksini)

> 해가 지면 도시는 어둑시니에게 먹힌다. 불을 밝힌 땅만 내일을 맞는다.

**강북 3구 연합**(마포·용산·중구)과 **강남 3구 연합**(영등포·동작·관악)이 어둠에 덮인 도시를 구청에서부터 밝혀 나가는 지도 땅따먹기 웹게임. 구조는 **개척 → 접촉 → 쟁탈**: 처음엔 서로 멀리 떨어져 어둠을 밝히고(개척), 불빛이 맞닿으면(접촉) 그때부터 서로의 등불을 빼앗는다(쟁탈).
실제 서울 일출·일몰 시각으로 낮과 밤이 바뀐다. 지도는 **서울 25개 구 전역**이고, 그중 시범 전선 6개 구만 열려 있다. 나머지 19개 구는 봉인된 땅으로 보이고, 누르면 "열어 주세요" 투표를 할 수 있다.

- 주소: https://eoduk.woongstudio.com (예비 https://eoduk.tedcheon.workers.dev)
- 기획: 2026-11-27 서비스 기획서 → v2 비주얼 작업지시서 → **v3 규칙 작업지시서(2026-11-27, 이 문서의 기준)**.
- 틀: [app_starter](https://github.com/jrchun/app_starter) Supabase 모드. 배포·허브 연동 절차는 `docs/AGENT_SETUP.md`, `docs/SETUP.md`, `docs/HUB.md`.

## 하루 흐름

| 시간(KST) | 이름 | 할 수 있는 것 |
|---|---|---|
| 일출 ~ 일몰 | 낮 | 개척, 진군(공격), 증원, 깃발. 일몰 전에 도착하지 못하는 개척·진군은 보낼 수 없음 |
| 일몰 ~ 자정 | 밤 — 어둑시니 | 증원만. 어둠이 8번 밀려온다(틱 간격 = 밤 길이 ÷ 8). 병력 생산 절반 |
| 자정 ~ 일출 | 봉인 | 휴전. 자정에 "오늘의 성적"(구별 밝힌 칸, 지킨 비율)을 기록 |
| 일요일 밤 | 긴 밤 | 어둠 압력 1.5배. 자정이 지나면 연합 점수로 시즌 정산 → 세계 초기화(월요일 0시 새 시즌) |

## 규칙과 숫자 (`web/js/rules.js` = `supabase/schema.sql`)

| 항목 | 값 |
|---|---|
| 시즌 시작 | 모든 칸이 어둠. **구청 칸 6개만** 켜져 있다(수비 100). 구청은 빼앗을 수도, 밤에 먹힐 수도 없다 |
| 개척 | 우리 **연합** 등불에 붙은 어둠·잿빛 칸에 병력을 보낸다. 필요 병력 = 20 + 5 × 내 구청까지 칸 거리. 한강 다리 +10, 샛강 다리(여의교·서울교) +45, 잿빛 칸은 절반. 같은 연합 여러 사람이 나눠 보내도 합쳐진다. 켜지면 수비 = 보낸 병력 − 필요(최소 10) |
| 진군(공격) | 우리 연합 등불에 붙은 **다른 연합** 등불 칸으로. 시간 = 10분 + 3분 × 거리(최대 40분). 잿빛 칸은 절반 |
| 증원 | 같은 연합의 어느 칸이든(밤에도 가능) |
| 판정 | 공격력 × (0.9~1.1) > 방어력이면 점령. 방어력 = 수비 × 1.2 × (1 + 붙은 같은 연합 칸당 5%, 최대 30%) × 구 유형 보정 |
| 밤 침식 | **어둠(미개척)과 맞닿은 등불 칸**(개척지 가장자리)에 압력 30 + 10 × 틱(+ 응시). 압력 > 수비 × 어둠 저항이면 잿빛, 버티면 수비가 압력 × 0.25 ÷ 저항만큼 깎인다 |
| 응시 | 밤에 그 칸을 보고 있는 **고유 사람** 1명당 압력 +3(최대 +30). 등불 정령은 세지 않는다 |
| 여의도 | 샛강으로 둘러싸인 섬. 다리 8개(한강 6 + 샛강 2)로만 들어간다. 랜드마크 3곳(국회의사당·더현대·파크원·63빌딩) |
| 랜드마크 효과 | 서울역·영등포역·더현대·파크원 병력 생산 +5%, 국회의사당 진군·개척 시간 -10%, 63빌딩 밤 저항 +10%, 남산서울타워·보라매공원 시야 +2칸. 가진 연합 전체에 적용, 같은 종류 합계 최대 15% |
| 시즌 점수 | 연합별 등불 칸 + 랜드마크 칸 × 3. 구별 점수도 순위에 보인다 |
| 등불 정령 | 사람이 적을 때 채워 주는 보조 플레이어(이름에 "등불 정령"). 연합마다 max(0, 8 − 최근 24시간 활동한 사람), 최대 6. 08~20시에 2~3시간마다 움직이고 하루 행동량은 사람 행동의 2/3 안쪽. 랜드마크 칸은 켜지 못한다 |
| 병력 생산 | 1인 시간당 30명(밤·봉인 절반), 상한 90. 처음 60명. 인원 보정 0.7~1.3(사람만 셈) |
| 닉네임 | 1~12자, 다른 사람과 겹칠 수 없음. 인디언식 추천 이름(`web/js/names.js`) |

밸런스(시뮬레이터 `node scripts/sim.mjs`, 시드 20개 × 7일, 결과 `sim-report.json`)
- 목표: 5/5 기준 수요일까지 첫 접촉, 여의도 랜드마크를 양쪽이 비슷하게, 10/5에서도 작은 쪽 점수가 큰 쪽의 50% 이상.
- 처음 값(모든 다리 +10)에서는 영등포구청 바로 옆이 여의교라 강남이 여의도 랜드마크를 60/60 가져갔다. **샛강 다리만 +45**로 올리자 처음 밝힌 쪽 강북 17 · 강남 14, 수요일까지 접촉 100%(평균 2.2일째), 10/5 비율 0.93.
- 남은 관찰: 밤 침식이 개척지 가장자리를 거의 다 먹는다(밤마다 약 40칸). 그래서 랜드마크도 일요일 밤까지 남는 경우가 드물다. 실제 플레이를 보고 조정한다(`docs/BACKLOG.md`).

구 유형(시범 전선): 마포·동작 강변형(다리 방어 +30%), 용산·관악 설화형(밤 저항 +25%, 낮 공격 -10%), 중구·영등포 도심형(진군 -25%, 밤 저항 -15%).

### 화면(v2 비주얼, 2026-11-27 작업지시서)
- (2026-11-27 고침) 지도는 북쪽이 위, 한강이 서→동 가로인 HD-2D 쿼터뷰. 처음 배율부터 칸(헥스) 결이 보인다. 칸 시트가 열린 채 다른 곳을 누르면 선택만 취소된다. 숫자도 본문 글꼴(시간 막대 포함).
- (2026-11-27 고침) 로그인이 안 돼 있으면 들어올 때마다 온보딩(어떤 게임인지)부터 뜬다. "먼저 지도 둘러보기"로 닫는다.
- (2026-11-27 고침) 폰 아래 버튼 줄(진군·증원·메뉴)을 없앴다. 칸을 누르면 그 칸에서 할 수 있는 일(개척·진군·증원·깃발)이 시트로 뜨고, 메뉴는 헤더 오른쪽(≡, 공격이 오면 빨간 점). 낮에는 안내 칩을 누르면 개척하기 좋은 칸으로 간다. 공격이 오면 경고 카드의 [증원].
- 기본 카메라는 우리 구 전선(둘러보는 중이면 국회의사당 일대)을 크게 당겨 본다. "우리 전선으로"로 돌아온다.
- 칸 위 숫자·등불을 없앴다. 수비는 칸 상세·경고 카드·PC 패널에서 본다. 이름표는 공격받는 칸·고른 칸 → 랜드마크 → 우리 칸 → 나머지 순으로 그리고 겹치면 건너뛴다.
- 안개: 우리 구와 바깥 2줄 밖. 낮은 구름문, 밤은 어둑시니 눈. 보이는 것만 가린다.
- 폰(1023px 이하): 헤더(시간 막대 / 구·점수·병력·메뉴) / 지도(경고 카드·안내 칩·우리 전선으로). PC(1024px 이상): 헤더 한 줄, 지도 + 오른쪽 패널 5카드(다가오는 공격·진행 중인 진군·깃발·구 순위·오픈채팅), 칸 상세 시트는 패널 자리에 열린다.

### 데이터가 흐르는 길
1. 화면은 공개 키로 Supabase에 직접 붙는다. 표는 **읽기만** 열려 있다(RLS). 플레이어 정보는 자기 것만, 깃발은 같은 연합끼리만 보인다.
2. 개척·진군·증원·가입·깃발·투표는 `security definer` 함수(`settle`, `send_march`, `reinforce`, `join_game`, `plant_flag`, `vote_gu`)로만 한다. 함수가 낮/밤, 인접, 병력, 일몰 전 도착을 검사한다.
3. 진군 도착 판정은 **지연 계산**: 누가 `game_state`를 부르거나 예약 작업이 돌 때 `private.advance()`가 도착 시각이 지난 진군부터 차례로 판정하고, 지난 밤 틱을 처리한다. 여러 번 불러도 안전하다(이미 한 일은 다시 안 함, advisory lock).
4. `tiles`·`marches`가 바뀌면 Supabase Realtime이 화면에 알리고, 화면은 `game_state`를 다시 받는다.
5. 내부 함수는 API에 드러나지 않는 `private` 스키마에 있다.

### 고칠 때
- 숫자를 바꾸면 `web/js/rules.js`와 `supabase/schema.sql` 둘 다 고치고 `tests/rules.test.js`도 맞춘다.
- 스키마를 바꾸면 Supabase MCP `apply_migration`으로 적용한다(`create or replace`라 여러 번 실행해도 된다). 처음부터라면 `schema.sql` → `seed.sql` → `select private.init_world();`.
- 지도를 바꾸면 `node scripts/build_map.mjs` → `web/data/map.json`·`supabase/seed.sql`이 바뀐다. 칸 번호가 달라지므로 **시즌 사이에만** 적용한다(진행 중인 진군·깃발이 엉뚱한 칸을 가리킨다).
- 지도 출처: 통계청 센서스용 행정구역경계(2013), `southkorea/seoul-maps`(`THIRD_PARTY_NOTICES.md`).
