# 어둑시니 (Eoduksini)

> 해가 지면 도시는 어둑시니에게 먹힌다. 불을 밝힌 땅만 내일을 맞는다.

동네(구)끼리 낮에는 서로의 등불(헥스 칸)을 빼앗고, 밤에는 어둠에 맞서 버티는 지도 땅따먹기 웹게임.
실제 서울 일출·일몰 시각으로 낮과 밤이 바뀐다. 지도는 **서울 25개 구 전역**이고, 그중 한강을 사이에 둔 **시범 전선 6개 구**(마포·용산·중구 / 영등포·동작·관악)만 열려 있다. 나머지 19개 구는 봉인된 땅으로 보이고, 누르면 "열어 주세요" 투표를 할 수 있다.

- 주소: https://eoduk.woongstudio.com (예비 https://eoduk.tedcheon.workers.dev)
- 기획서: 2026-11-27 서비스 기획서(1~16절). 이 문서의 숫자는 그 9절 "밸런스 초기값"에서 출발해 시험하며 고친 값이다.
- 틀: [app_starter](https://github.com/jrchun/app_starter) Supabase 모드. 배포·허브 연동 절차는 `docs/AGENT_SETUP.md`, `docs/SETUP.md`, `docs/HUB.md`.

## 하루 흐름

| 시간(KST) | 이름 | 할 수 있는 것 |
|---|---|---|
| 일출 ~ 일몰 | 낮 — 등불 쟁탈전 | 진군, 증원, 깃발. 일몰 30분 전은 마지막 러시(일몰 전에 도착 못 하는 진군은 보낼 수 없음) |
| 일몰 ~ 자정 | 밤 — 어둑시니 | 증원만. 어둠이 8번 밀려온다(틱 간격 = 밤 길이 ÷ 8). 병력 생산 절반 |
| 자정 ~ 일출 | 봉인 | 휴전. 자정에 구별 살아남은 등불을 기록 |
| 일요일 밤 | 긴 밤 | 어둠 압력 1.5배. 자정이 지나면 시즌 정산 → 세계 초기화(월요일 0시 새 시즌) |

## 규칙과 숫자 (`web/js/rules.js` = `supabase/schema.sql`)

| 항목 | 값 |
|---|---|
| 병력 생산 | 1인 시간당 30명(밤·봉인 절반), 상한 90. 처음 60명 |
| 인원 보정 | 생산 × 1/√(구 인원 ÷ 6개 구 평균), 0.7~1.3 |
| 칸 수비 | 시즌 시작 100, 중립 다리 40, 상한 300. 칸 수비는 모두 등롱지기(수비 1.2) |
| 진군 | 우리 땅에 맞닿은 남의 칸으로. 시간 = 10분 + 3분 × 거리(최대 40분). 잿빛 칸은 절반 |
| 유닛 | 진군 때 횃불꾼 비율을 고른다. 횃불꾼 공격 1.2, 등롱지기 공격 0.8 |
| 판정 | 공격력 × (0.9~1.1) > 방어력이면 점령. 방어력 = 수비 × 1.2 × (1 + 붙은 우리 칸당 5%, 최대 30%) × 구 유형 보정 |
| 점령 후 수비 | 남은 병력(최소 10). 지면 수비가 공격력만큼 비례해 깎인다 |
| 밤 침식 | 어둠(지도 가장자리 + **지난밤까지** 잿빛이 된 칸)과 맞닿은 칸에 압력 30 + 10 × 틱(+ 응시). 압력 > 수비 × 어둠 저항이면 잿빛, 버티면 수비가 압력 × 0.25 ÷ 저항만큼 깎인다 |
| 어둠 저항 | 등롱지기 1.2 × 구 유형(설화형 1.25, 도심형 0.85) |
| 응시 | 밤에 그 칸을 보고 있는 사람 1명당 압력 +3(최대 +30). 화면에 "지금 이 칸을 보는 사람 n명" |
| 기여도 | 증원 1명당 1점, 점령 1번에 20점 |
| 닉네임 | 1~12자, 다른 사람과 겹칠 수 없음(대소문자·앞뒤 공백 무시). 가입 화면에 인디언식 추천 이름(`web/js/names.js`)을 미리 채우고, 이미 쓰는 이름은 `nicknames_free`로 걸러 낸다 |

시험하며 바꾼 것(기획서 초기값과 다른 점)
- 오늘 밤 먹힌 칸은 **다음 밤부터** 어둠이 된다. 처음 식으로는 먹힌 칸이 바로 어둠이 되어 연쇄로 번져, 아무도 지키지 않으면 하룻밤에 지도의 85%가 먹혔다. 지금은 하룻밤에 가장자리 한 겹.
- 버틴 칸이 잃는 수비를 압력의 50% → 25%로. 50%면 가장자리 칸은 상한 300으로도 밤을 넘기지 못했다. 지금은 수비 약 230이면 설화형 가장자리가 버틴다.
- 중립 다리 60 → 40. 첫날 혼자서도 다리를 노릴 수 있게.

구 유형(시범 전선): 마포·동작 강변형(다리 방어 +30%), 용산·관악 설화형(밤 저항 +25%, 낮 공격 -10%), 중구·영등포 도심형(진군 -25%, 밤 저항 -15%). 산악형·마을형 규칙도 들어 있다(25개 구로 넓힐 때 쓴다).

  js/sprites.js         작은 도트(등불·눈·깃발)와 PNG 스프라이트 불러오기(실패하면 작은 도트로 대신)

  data/map.json         서울 전역 칸 575개(열린 칸 1~120 + 봉인된 칸 1001~), 한강 중심선·다리·밤섬(scripts/build_map.mjs가 만든다)

### 화면(v2 비주얼, 2026-11-27 작업지시서)
- 기본 카메라는 우리 구 전선(둘러보는 중이면 국회의사당 일대)을 크게 당겨 본다. "우리 전선으로"로 돌아온다.
- 칸 위 숫자·등불을 없앴다. 수비는 칸 상세·경고 카드·PC 패널에서 본다. 이름표는 공격받는 칸·고른 칸 → 랜드마크 → 우리 칸 → 나머지 순으로 그리고 겹치면 건너뛴다.
- 안개: 우리 구와 바깥 2줄 밖. 낮은 구름문, 밤은 어둑시니 눈. 보이는 것만 가린다.
- 폰(1023px 이하): 헤더 / 병력 줄 / 지도(경고 카드·안내 칩·우리 전선으로) / 깃발 줄 + 진군·증원·메뉴. PC(1024px 이상): 헤더 한 줄, 지도 + 오른쪽 패널 5카드(다가오는 공격·진행 중인 진군·깃발·구 순위·오픈채팅), 칸 상세 시트는 패널 자리에 열린다.

### 데이터가 흐르는 길
1. 화면은 공개 키로 Supabase에 직접 붙는다. 표는 **읽기만** 열려 있다(RLS). 플레이어 정보는 자기 것만, 깃발은 같은 구끼리만 보인다.
2. 진군·증원·가입·깃발은 `security definer` 함수(`send_march`, `reinforce`, `join_game`, `plant_flag`)로만 한다. 함수가 낮/밤, 인접, 병력, 일몰 전 도착을 검사한다.
3. 진군 도착 판정은 **지연 계산**: 누가 `game_state`를 부르거나 예약 작업이 돌 때 `private.advance()`가 도착 시각이 지난 진군부터 차례로 판정하고, 지난 밤 틱을 처리한다. 여러 번 불러도 안전하다(이미 한 일은 다시 안 함, advisory lock).
4. `tiles`·`marches`가 바뀌면 Supabase Realtime이 화면에 알리고, 화면은 `game_state`를 다시 받는다.
5. 내부 함수는 API에 드러나지 않는 `private` 스키마에 있다.

### 고칠 때
- 숫자를 바꾸면 `web/js/rules.js`와 `supabase/schema.sql` 둘 다 고치고 `tests/rules.test.js`도 맞춘다.
- 스키마를 바꾸면 Supabase MCP `apply_migration`으로 적용한다(`create or replace`라 여러 번 실행해도 된다). 처음부터라면 `schema.sql` → `seed.sql` → `select private.init_world();`.
- 지도를 바꾸면 `node scripts/build_map.mjs` → `web/data/map.json`·`supabase/seed.sql`이 바뀐다. 칸 번호가 달라지므로 **시즌 사이에만** 적용한다(진행 중인 진군·깃발이 엉뚱한 칸을 가리킨다).
- 지도 출처: 통계청 센서스용 행정구역경계(2013), `southkorea/seoul-maps`(`THIRD_PARTY_NOTICES.md`).

## 운영

- 테스트: `npm test`
- 로컬: `npx wrangler@4 dev` → http://localhost:8787 (Supabase는 실제 프로젝트에 붙는다. 로컬에서는 `window.eodukDebug`로 상태를 볼 수 있다)
- 배포: `main`에 Merge하면 Cloudflare Workers Builds가 자동 배포. 확인은 `node scripts/check_site.mjs https://eoduk.woongstudio.com`
- Supabase 프로젝트: `eoduk`(서울, ref `mdusiykkpllzkkemgcxw`)
- 오픈채팅방을 만들면 `web/js/links.js`에 주소를 넣는다.
- 시즌을 손으로 초기화(시험 뒤 등): Supabase SQL에서 `select private.reset_world();` — 모든 칸이 시작 상태로 돌아간다.
