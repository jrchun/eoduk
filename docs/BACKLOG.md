# 나중에 할 일 (백로그)

지금 당장 하지 않고 미뤄 둔 일. 우선순위: **기능이 제대로 도는 것 > 디자인 통일성**.
사용자가 "백로그 진행"이라고 하면 위에서부터 하나씩 꺼내 PR로 처리하고, 끝나면 여기서 지운다.

## 어둑시니: 기획서에 있지만 첫 버전에서 미룬 것
- **웹 푸시(진군 알림, 일몰 30분 전 알림).** 지금은 탭 제목에 남은 시간, 화면 안 공격 경고, 소리(기본 꺼짐)만 있다. 할 일: VAPID 키 만들기 → 개인 키는 Worker Secret(Cloudflare MCP로 넣을 수 있음) → 서비스 워커 + 구독 저장 표(`push_subs`, RLS) → Worker에서 Web Push 암호화(aes128gcm)로 보내기 → 예약 작업이 일몰 30분 전·진군 생성 때 보냄. 아이폰은 홈 화면에 추가해야 받는다(추가하면 병력 보상).
- **나머지 랜드마크 그림.** v2(2026-11-27)에서 유닛 3종(48×64)과 여의도 랜드마크 5종(63빌딩·파크원·더현대·IFC·국회의사당)을 넣었다. 남산서울타워·서울역·DDP·현충원 등 13곳은 아직 마름모 표시 + 이름표. 같은 쿼터뷰 도트로 그리면 `web/assets/landmarks/landmark-<키>.png`에 넣고 `scripts/build_map.mjs`의 `SPRITES`에 위치를 더한다. PixelLab으로 유닛을 다시 만들면 같은 파일 이름·크기로 덮어쓴다.
- **도깨비불 유닛(2단계).** 그림 파일만 들어 있다(`web/assets/units/dokkaebifire-*`). 규칙(진군 -40%, 진군선 늦게 보임, 비용 2배)은 아직 없다.
- **시야 규칙.** v2 안개는 보이는 것만 가린다(우리 구 + 바깥 2줄 밖). 정보까지 숨길지는 기획서 열린 질문.
- **해 질 녘 연출 다듬기.** v1의 일몰 1시간 전 노을 덧칠은 v2 쿼터뷰에서 뺐다.
- **산악형 "진군선 10분 먼저 보임".** 지금은 모든 진군선이 처음부터 모두에게 보인다(시범 전선에 산악형 구가 없음). 25개 구로 넓힐 때 진군을 늦게 공개하는 규칙과 함께 넣는다.
- **이메일 없이 들어오기.** 지금은 이메일·비밀번호. 카카오 로그인(Supabase 소셜) 검토.
- **밸런스 다듬기(v3).** `scripts/sim.mjs`로 본 결과 밤 침식이 개척지 가장자리를 거의 다 먹는다(밤마다 약 40칸, 새로 켠 칸 수비가 10 안팎이라). 여의도 랜드마크도 일요일 밤까지 남는 일이 드물다. 실제 플레이를 본 뒤 후보: 개척 후 수비를 필요 병력의 일부만큼 남기기(sim `keep`), 어둠과 맞닿은 면 수에 비례한 압력(sim `exposure`). 10/10에서는 강북이 여의도를 더 많이 가져간다(처음 48:12).
- **랜드마크 그림 다시 얹기.** v3에서도 걷어 둔 상태(`web/assets/landmarks`, `map.json` `sprites`는 남김). 지도 우선순위(서울 → 구 → 점령 상태)를 해치지 않게 하나씩.
- **안개 정보 숨기기.** v3는 화면에서만 가린다(서버 `game_state`는 모든 칸을 내려줌).
- 기획서 15절 백로그(구 수호신 강림, 시즌 이야기, 개인 성장, 임시 타락, GPS 토박이, 도깨비불)는 재미 검증 뒤.

## 확인이 남은 것 (다음 새 앱을 만들 때 같이)
- **`gh repo create --template`으로 템플릿 저장소 만들기 확인.** 사람이 GitHub "Use this template"을 누르는 대신 AI가 만들 수 있는지.
- **Codex에서 Cloudflare MCP 연결 확인.** `AGENTS.md` 안내대로 되는지.

## 디자인 통일성 (나중에)
- **뎀브란트(Dembrandt) MCP로 디자인 초안 잡기.** 참고 사이트 주소를 주면 색·글꼴·간격 같은 디자인 값(토큰)을 뽑아 주는 도구. 로그인·API 키 없이 `npx -y dembrandt mcp`로 돈다.
  - 할 일: 저장소에 `.mcp.json` 추가(버전 고정) → `docs/AGENT_SETUP.md` 기획 단계에 "참고 사이트가 있나요?" 질문 추가 → 뽑은 값을 `web/styles.css` CSS 변수(라이트·다크)로 옮기고 400px 화면 캡처로 초안 보여 주기 → Codex용 설정은 `AGENTS.md`에 따로.
  - 주의: 분위기·간격 규칙만 참고하고 남의 로고·브랜드를 그대로 쓰지 않는다. 클라우드 세션에서는 참고 사이트 주소를 접속 허용 목록에 넣어야 하고, 컨테이너에서는 `noSandbox` 옵션을 켠다.
  - 출처: https://github.com/dembrandt/dembrandt (README의 "AI Agent Integration (MCP)")
- **앱들 사이 공통 디자인 규칙.** 여러 앱을 만든 뒤, 같은 색·글꼴·부품 모양을 쓰도록 `web/styles.css` 기본값을 정리.

## 나중에 볼 도구
